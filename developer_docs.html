Query public market snapshots and quantitative research outputs from a small, inspectable API. This reference shows the working routes and how to authenticate. The interactive OpenAPI explorer is available separately.

TransportHTTPS + JSON
Trial500 requests total
01 / ACCESS

Get a Starter key

Create a trial client from the API access form on the dashboard ↗. Verify your email, then copy the key when it appears. It is shown once.

01RegisterSubmit your company or project name and email.
02VerifyUse the code sent to your inbox within 15 minutes.
03Store the keySave the returned key securely. The dashboard will not show it again.

For programmatic registration, use POST /api/v1/auth/register with company_name and email, followed by POST /api/v1/auth/verify-email with email and token. See exact schemas in the interactive API ↗.

02 / AUTHENTICATION

Send your key in a header

Authenticated endpoints expect an X-API-Key request header. Keep the key on your server; do not embed it in public browser code or a repository.

Example · market metric
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://alpha-metrics-engine.onrender.com/api/v1/metrics/BTCUSDT"

To inspect your allowance, call GET /api/v1/auth/usage with the same header, or use the key checker on the dashboard ↗. The checker does not store your key between visits.

03 / ENDPOINTS

Available routes

Use the interactive explorer for query parameters, request bodies, and response schemas.

GET/api/v1/metrics/{ticker}

Price, change, RSI, moving average, and momentum status. API key required.

GET/api/v1/quant/backtest/{ticker}

One-year RSI backtest result. API key required.

GET/api/v1/quant/var/{ticker}

Monte Carlo VaR and CVaR. API key required; days and simulations are optional.

GET/api/v1/quant/correlation?symbols=AAPL,TSLA

Correlation matrix for 2–12 distinct symbols. API key required.

GET/api/v1/auth/usage

Current plan, rate limit, and remaining trial requests. API key required.

GET/api/v1/demo/quant/backtest/{ticker}

Rate-limited public route for supported dashboard symbols.

WS/ws/stream · /ws/hft-risk

Public market and risk streams used by the dashboard. Availability depends on upstream feeds.

Example · portfolio correlation
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://alpha-metrics-engine.onrender.com/api/v1/quant/correlation?symbols=AAPL,TSLA"
04 / OPERATING NOTES

Limits & data

The Starter trial includes 500 requests total and a limit of 60 requests per minute. The current allowance does not automatically reset each month. Exceeding a rate limit returns HTTP 429; upstream market failures may return HTTP 502.

Research data. Quotes and history come from public exchange and Yahoo Finance sources. Availability, latency, and usage rights depend on those providers. Treat analytical outputs as research examples, not investment advice.
